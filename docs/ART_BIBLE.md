# 아트 바이블 (3줄 + 팔레트)

이미 정한 그림 방향(11-21 네온 골목, 11-28 화풍 통일)을 한곳에 적은 것이다. 새 그림·이펙트·UI 색은 여기서 고른다.
Unity 공식 플러그인 `craft-game-floors`의 품질 채점표가 이 문서를 기준으로 "색 통일·화풍 통일"을 채점한다.

1. **화풍**: 비 오는 하층 네온 골목의 도트 그림이다.
   - 캐릭터·지형은 PPU 48, 배경은 2px 격자다.
   - **이펙트·자리표시도 도트**로 그린다(점 필터, 24px/단위). 매끈한 사각형·선·원은 쓰지 않는다.
2. **팔레트**: `Tools/art/palettes/alley.png`(48색)가 원본이다. 역할별 대표색:
   | 역할 | 색 |
   |---|---|
   | 어둠·하늘 | `#070915` `#10142F` `#20295E` |
   | 벽·지형 | `#242E49` `#2F2F4E` `#544460` |
   | 리아 | `#EFEBDB`(머리) `#35D8E2`(목도리) |
   | 청록 네온 = 플레이어·안전 | `#17CDCD` `#35D8E2` `#67E1E9` |
   | 마젠타 네온 = 적 마력·간판 | `#96208F` `#E732DC` `#ED65E4` |
   | 주황 = 충돌·따뜻한 창문 | `#E79F26` `#EDB75C` |
   - **예외**: 위험 예고의 빨강(`GroundWarning`)은 팔레트 밖이지만 읽기 쉬움을 위해 유지한다.
3. **분위기**: 해는 없다. 간판·창문·네온이 광원이다. 그림자는 검정이 아니라 남색이고, 비가 내린다.

## 지킬 것

- 배경은 지형보다 한 단계 어둡다(배경 막 알파 0.62). 밟는 지형이 먼저 읽혀야 한다.
- 빛나는 것은 한 화면에 몇 개만 둔다. 다 빛나면 아무것도 안 보인다.
- 자리표시 이펙트는 `Core/PixelPatterns`의 도트 무늬(빛줄기·사선·막·디더·고리·점)를 쓴다.
