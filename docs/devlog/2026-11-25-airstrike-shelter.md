# 2026-11-25 · 추적대장 공습을 네온 차양 아래로 피하다

작성: Claude (구현: Codex, 검토·수정: Claude)

## "공습탄이 뭘 말하는지 모르겠어"

11-22 작업 보고에서 공습탄 착탄 원 일부가 공중의 난간 발판 위에 찍힌다는 문제를 물었다. 사람은 공습탄이 뭔지부터 몰랐다. 보스 이름과 패턴 이름을 다 바꾼 직후라, 보고서에서 새 이름만 쓰면 전달이 안 된다는 걸 배웠다.

공습탄 = 추적대장이 하늘에서 떨어뜨리는 폭탄. 예전 사슴왕의 낙엽 폭풍을 이름만 바꾼 것이다.

두 가지 안을 설명했다.

1. 난간을 뚫고 땅까지 떨어진다.
2. 지금처럼 난간에 맞으면 거기서 터진다.

사람의 답은 둘 다 아니었다.

> 떨어질때 발판이 생겨서 그 아래로 가야지 피할수있는 패턴이면 좋을거같아

## 바뀐 공습 패턴

| | 전 | 후 |
|---|---|---|
| 피하는 법 | 탄 사이 빈틈(약 1.7칸)에 서 있기 | **엄폐판 아래로 뛰어가기** |
| 엄폐판 | 없음 | 평소 2개 / 분노 시 1개, 리아 양옆 |
| 탄 수 | 6~8발 | 1.2칸 간격 약 11발, 바닥에 빈틈 없음 |
| 착탄 범위 피해 | 없음 (떨어지는 길에 닿을 때만) | 반경 0.7칸 |
| 난간 발판 | 탄이 난간 위에서 터짐 | 난간을 뚫고 땅까지 |
| 예고 시간 | 0.6초 | **0.9초** (뛰어갈 시간) |

- 엄폐판은 추적대장의 공습 신호에 떨어져 걸린 **네온 간판 차양**이다. 지면 위 2.2칸, 폭 2.4칸, 0.15초 만에 위에서 내려와 자리 잡는다.
- 차양 아래 바닥에는 **청록색 안전 표시**를 깐다. 붉은 착탄 원과 구분된다.
- 차양은 리아와 충돌하지 않는다. 밑으로 걸어 들어가도 되고 점프로 뚫고 지나가도 된다. 공습탄만 막는다.
- 차양 위에 맞은 탄은 차양을 흔들고 불꽃을 튀긴다. 폭발은 아래로 새지 않는다.
- 벽이나 낭떠러지 너머, 걸어서 제때 못 가는 곳에는 차양을 만들지 않는다. 안전한 자리를 하나도 못 만들면 공습을 생략한다.
- 새 그림 없이 사각형에 마젠타·청록 네온 테두리를 둘렀다.

## 검토하면서 고친 것

- **차양 두 개가 리아 머리 위에 붙어서 떨어졌다.** 최소 거리를 차양 중심 기준 1.5칸으로 잡았는데, 차양 폭이 2.4칸이라 서 있던 자리가 이미 지붕 아래였다. 그래서 움직일 필요가 없었다. 거리 기준을 **차양 가장자리까지 1.2~2.8칸**으로 바꿨고, "시작 자리는 안전하지 않다" 검사를 테스트에 추가했다.
- 차양이 얇은 선(0.18칸)이라 발판처럼 안 보여서 0.32칸으로 두껍게 했다.
- 브레인 악셀 중 감속 테스트가 실패했다. 테스트가 `Time.timeScale`을 직접 바꿨지만 씬의 시간 관리자가 매 프레임 되돌렸기 때문이다. 게임 버그는 아니다. 브레인 악셀 감속 채널을 쓰도록 테스트를 고쳤다.

## 오후 · 플레이 피드백 2차

사람이 직접 해 보고 준 피드백:

> 전보다 확실히 쉬워진거같아 근데 패턴이 반응하기가너무힘들어 1자로 돌진하는건 점프높이보다 보스가 커서 피할방법이 아예없고

> 처음에 이미지생성전에 만든거만큼의 타격감이 없어졌어

### 돌진은 점프로 넘는다

수치를 보니 정말로 피할 방법이 없었다. 리아의 점프 정점은 3.0칸이고 추적대장 몸 판정은 2.6칸이라, 넘으려면 거의 프레임 단위로 맞춰야 했다. 그림 속 추적대장은 그보다 훨씬 커서 넘을 수 있다는 생각조차 들지 않았다.

처음에는 "대시 무적으로 뚫고 지나가기"(데드 셀·스컬식)를 제안했다. 사람은 **"아니야 돌진은 점프로 피하는게 맞아"**라고 했다. 대시 무적을 0.1초에서 늘렸던 것은 되돌렸다.

| | 전 | 후 |
|---|---|---|
| 돌진 중 판정 높이 | 2.6칸 (점프 정점 3.0) | **1.5칸** (몸을 숙인 어깨 박치기) |
| 점프 타이밍 여유 | 사실상 0 | 판정 위에 떠 있는 0.45초 − 보스 통과 0.23초 ≈ **0.22초** |
| 돌진 그림 | 서 있는 자세 그대로 | 납작하게 숙이고 앞으로 15° 기울임 |
| 돌진 예고 | 0.7초 | **1.0초** |
| 휘두르기 예고 | 0.45초 | **0.65초** |

- 점프로 넘을 여유가 0.15초 아래로 줄면 실패하는 테스트를 넣었다.
- 숙인 자세는 지금 있는 그림을 눌러서 만든 임시 모습이다. 몸을 낮춘 돌진 그림을 따로 그려야 한다.

### 타격감: 칼보다 타격이 먼저 일어나고 있었다

맨 처음 손맛 프로토타입(11-18, 도형 캐릭터)과 지금을 비교했다. 히트스톱·흔들림·넉백 수치는 오히려 지금이 더 세다. 차이는 **그림 애니메이션**이었다.

- 리아 공격 그림 6장 중 칼을 앞으로 뻗은 장면은 3번째다.
- 그림을 공격 길이(0.27초)에 고르게 늘려 재생해서, 3번째 장면은 0.09초에 나왔다.
- 실제 타격(번쩍임·히트스톱·흔들림)은 **0.04초**에 일어났다. 리아가 아직 칼을 뒤로 들고 있을 때 적이 맞고 있었다.
- 도형 시절에는 그림이 없어서 타격과 베기 이펙트가 같은 순간에 보였다.

**고친 것**: 공격 그림을 두 구간으로 나눠 재생한다. 판정 전에는 들어 올리는 1~2번째 장면, **판정이 생기는 순간에 칼을 뻗은 3번째 장면**, 나머지는 남은 시간에 나눈다. 판정 순간에 3번째 장면이 보이는지 확인하는 테스트를 넣었다.
