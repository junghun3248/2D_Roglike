작성: Claude

## "게임이 너무 어렵다"

어디가 어려운지 물었더니 답은 **"잡몹이 너무 안 죽는다."** 받는 데미지·웨이브 수·보스는 원인이 아니었다.

수치를 보니 진짜 원인은 따로 있었다. 적 체력이 지역이 아니라 **방 하나 넘어갈 때마다 1.8배씩** 곱해지고 있었다.

| | 전 | 후 |
|---|---|---|
| 방마다 체력 배율 | ×1.8 (보스 방 약 **×19**) | ×1.18 (보스 방 약 **×2.3**) |
| 멧돼지 (첫 전투 방) | 평타 13대, 세 번째 방에선 약 40대 | 약 5대 |
| 다람쥐 | 8대 | 약 3대 |
| 엘리트 체력 | ×2.5 | ×2.0 |
| 보스 | 11.3만 | 약 5천 (평균 강화로 60~90초 목표) |

- 기준은 스컬·데드셀 초반 지역 관례: 강화 없이 일반 적 4~6대, 원거리 적 3~4대.
- 나중에 수치를 바꾸다 다시 늘어지지 않도록 "몇 대에 죽는지"를 검사하는 테스트를 넣었다.

## 세계관 v0.1 → v0.3

"브레인 악셀이라는 기술을 만들고 싶다, 단어가 멋있다"에서 시작해 세계관을 통째로 바꿨다. 지금 그림을 버려도 된다는 결정과 함께.

- **세계**: 과학이 공기 중 마력을 전기처럼 쓰게 되자, 인간이 맨몸으로 마력을 다루는 마법사들을 학살했다 (정화의 해). 비 내리는 네온 도시.
- **마력의 규칙**: 인간은 충전한 마력을 총과 기계로 쓰고, 마법사는 공기 중 마력을 맨몸으로 끌어 쓴다. 마법사가 힘을 쓰면 **그 자리의 마력 농도가 옅어진다** → 탐지기가 그걸 찾는다.
- **주인공 리아**: 인간인 척 숨어 사는 마법사 생존자. 능력은 자기 뇌를 극한까지 가속하는 **브레인 악셀**.
- **마법사마다 고유 능력 하나**: 은신처 생존자들은 쓰레기 같지만 써먹을 구석이 있는 능력을 가졌다 (5초 전 위치로 되돌리기, 소리 차단 막, 기계 시계 3초 늦추기, 몸무게 조절 등).
- **두 개의 적**: 마법사를 사냥하는 인간 쪽 재단, 복수하려는 마법사 쪽 스승.
- **결말 세 가지**: 복수 / 숨김 / 드러냄(진 엔딩).
- 전체 내용: [WORLD.md](../WORLD.md)

### 브레인 악셀 = 예전 특수기의 새 이름과 새 효과

뇌만 가속했을 때 현실적으로 무엇이 좋아지는지부터 따졌다.

| 효과 | 현실 근거 | 게임 |
|---|---|---|
| 체감 시간 4~10배 느려짐 | 뇌가 1초에 처리하는 정보 증가 | 세상 0.25배속 (예전 특수기 손맛 그대로) |
| 동작 15~30% 빨라짐 | 근육 순서·타이밍 최적화 (근육 자체는 그대로) | 이동 ×1.2, 공격 속도 ×1.25 |
| 순간 힘 1.3~1.5배 | 뇌의 근력 제한 해제 | 피해 ×1.5 |
| 과열·저혈당 | 뇌는 몸 에너지의 20%를 씀 | 끝나면 **1.5초 반동** (이동 ×0.7, 공격 속도 ×0.8, 화면 번짐) |

- 게이지 = **주변 마력 농도**. 적을 쓰러뜨리면 부서진 기계에서 마력이 새어 나와 다시 찬다.
