# 2026-11-19 · 첫 플레이 피드백, UI 개편, 평타 손맛 다시 잡기

작성: Claude

## 오전 · 플레이 피드백 1차 반영

사람이 직접 플레이하고 준 피드백:

| 피드백 | 바꾼 것 |
|---|---|
| 키 세팅이 어색하다 | 액션 게임식 **Z 점프 · X 공격 · C 대시 · V 차지 · ASDF 스킬 · Space 특수기** |
| 대시가 있는데 스킬에 또 돌진이 있다 | 겹치는 돌진 스킬을 빼고 **정지 구역**(앞쪽 적을 얼림)으로 교체 |
| 평타는 콤보 없이 그냥 칼 휘두르기 | 3타 콤보 → **단일 베기** (내려찍기는 유지) |
| 대시도 평타처럼 상시 | 지상 대시 쿨다운 제거 |
| 바닥이 화면 위쪽에 있다 | 카메라를 내려 바닥을 화면 아래 약 23%에 |
| 공중 차지 공격을 맞히기 어렵다 | 차지 중 주변 시간 0.4배속 + 차지 후 돌진 |
| 몹이 너무 많다 | 연습장 동시 적 6 → 3 |
| 캐릭터가 그림 그대로 위아래로 움직인다 | 프레임 흔들림 보정(머리 떨림 6px → 0px), 기울기·늘이기·찌그러짐·반동 모션 추가 |

## 오후 · UI 개편

- 스컬·할로우 나이트식 배치: 좌하단 초상화·체력·특수기 게이지·원형 스킬 슬롯, 우상단 방 진행도, 보스 체력바는 화면 위 가운데.
- 저체력 비네트, Esc 일시정지 메뉴, 시너지 배지.
- 픽셀 한글 글꼴 **Galmuri**(SIL OFL) 적용. 흐릿하던 기본 글꼴 문제 해결.
- GPT로 스킬 아이콘 5종, 시너지 아이콘 6종, 주인공 초상화를 그려 넣었다.

## 저녁 · "평타 타격감이 왜 이렇게 안 좋아졌지?"

원인을 수치로 찾았다.

- 3타 콤보를 단일 베기로 바꾸면서 **가장 약한 첫 타 수치만 남았다** (히트스톱 0.05초, 흔들림 0.15). 무게를 주던 마무리 타격(0.12초, 0.45)이 사라졌다.
- 효과음이 하나도 없었다.
- 공중 공격은 휘두를 때마다 낙하를 멈추고 방향키를 무시해서 "무중력에서 허둥대는" 느낌이었다.

### 자동 플레이 기록 도구

Claude는 키보드로 직접 플레이할 수 없어서, **가상 키 입력으로 실제 게임을 돌리며 매 프레임 위치·카메라·시간 배율·소리를 CSV로 남기고 공격 장면을 연속 캡처하는 도구**(`PlaytestProbe`)를 만들었다. 고치기 전과 후를 같은 조건으로 비교한다.

### 고친 것과 측정 결과

| 항목 | 전 | 후 |
|---|---|---|
| 평타 히트스톱 / 흔들림 | 0.05초 / 0.15 | 0.075초 / 0.22 + 방향 카메라 킥 + 플레이어 반동 |
| 평타 리듬 | 같은 베기 반복 | 위·아래 베기 교대 (콤보 아님) |
| 연타 중 카메라 좌우 흔들림 | **2.78칸** (반동 때문에 시선이 뒤집힘) | **0.58칸** |
| 피격 번쩍임 | 몇 프레임 동안 흰 덩어리 | 짧고 부분적인 번쩍임 |
| 타격음 | 없음 → 첫 버전은 "치익" (중심 10.8kHz) | 묵직한 "퍽" (중심 2.1kHz, 저음 87%) |
| 공중 공격 | 휘두를 때마다 정지 | 정상 중력·좌우 조작, 맞혔을 때만 작은 상승 1회 |
| 베기 이펙트 | 납작한 직사각형 막대 | GPT로 그린 초승달 베기 + 타격점 빛 + 내려찍기 충격파 |

- 효과음 8종은 외부 파일 없이 Python으로 합성했다 (베기·타격·치명타·처치·대시·점프·착지·피격).
- 평가: 평타 5/10 → 7.5~8/10. 사람의 평: "이제 평타 모션은 좋은 것 같다."
