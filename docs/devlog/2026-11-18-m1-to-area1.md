# 2026-11-18 · 손맛 프로토타입부터 1지역까지 (M1 ~ M4 시작)

작성: Claude

하루 동안 마일스톤 세 개를 넘기고 첫 지역의 틀까지 만들었다.

## M1 · 손맛 프로토타입

- 이동·점프(2단)·대시, 3타 콤보, 적 1종(슬라임).
- 타격감 묶음: 히트스톱, 화면 흔들림, 피격 번쩍임, 넉백, 데미지 숫자.
- 특수기(당시 가칭 오버드라이브): 세상 0.25배속, 플레이어만 정상 속도, 타격 지점 줌인.
- 시간 제어를 한곳(TimeController)에 모았다: 히트스톱·특수기 감속·일시정지가 서로 꼬이지 않게.
- 통과 기준: "때리는 게 재밌다." 처음 결과물을 보고 "슈퍼마리오64보다 구리다"는 평가를 받아 스컬을 참고해 손맛을 다시 다듬었다.

## M2 · 런 루프

- 구역 진행 → 방을 깰 때마다 강화 3택1 → 보스 → 결과 화면 → 다시 시작.

## M3 · 성장

- 곱연산 빌드, 계열 태그별 시너지, 리롤, 억·조 단위 한국식 숫자 표기, 영구 성장(강화소).

## 오후 · 스킬과 그림

- 쿨다운 액티브 스킬 4종 + 쿨 없는 기본기. "평타가 없으면 손이 심심하다"는 피드백 반영.
- **그림을 GPT로 만들기 시작.** 캐릭터 에셋을 살 예산이 없어서, Codex(GPT 내장 이미지 생성)로 주인공·슬라임·배경·바닥을 뽑고 Python 스크립트로 프레임을 자르고 발밑을 맞춰 게임에 넣었다.
- 피드백: "그래픽이 허접한 것에 비해 타격감이 좋다."

## 저녁 · 세계관 v0.1과 1지역

- 세계관 초안: 시간이 멈춘 세계, 시계탑, 시간을 늦추는 검사. (11-20에 통째로 바뀐다)
- 1지역 '멈춘 숲': 방 6개(입구 → 전투 → 전투 → 휴식 → 엘리트 → 보스), 문이 잠기고 적을 다 잡으면 열림.
- 새 적: 돌진하는 태엽 멧돼지, 톱니를 던지는 다람쥐, 보스 태엽 사슴왕(돌진·뿔 휘두르기·낙엽 폭풍).

## 협업 방식이 정해진 날

- **Codex가 코딩과 그림, Claude가 검토, 사람이 플레이하고 피드백.**
- Claude는 검토할 때 실제 출시 게임과 비교해 방향을 잡는다. 장르 관례만 빌리고 다른 게임의 에셋은 베끼지 않는다.
