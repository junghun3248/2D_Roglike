## exe 빌드

- `Roglike/Build Windows exe` 메뉴와 배치 모드 빌더를 추가했다. 결과는 `Builds/Windows/2D_Roglike.exe`(git 제외).
- 은신처 → 런 → 연습장 3개 씬, 122MB.
- 빌드한 exe를 10초 실행해 오류 없이 은신처까지 뜨는 것을 확인했다.
- exe에는 창을 닫을 방법이 필요해서 일시정지 메뉴에 **게임 종료**를 넣었다.

## 브레인 악셀 중 무적

"시간이 멈춘 상태에서 공격을 넣는 듯한 스킬이라 속도감이 중요하다"는 요청에 따라, 발동 중에는 아무것도 맞지 않게 했다.
- 시간 기반 무적과 따로, 켜고 끄는 무적 출처(`SetInvulnerableSource`)를 `Health`에 추가했다.
- 끝나면 다시 맞는지 테스트로 지킨다.

기획 메모: 사람이 "상대도 같이 가속해서 서로 맞는" 장면을 원했다. 스토리 후반의 **가속 대결**로 GDD에 예정으로 적었다. 이 적에게는 악셀 무적이 통하지 않는다.

## 평타 타격감 3차

11-25에 공격 그림과 타격 순간을 맞췄는데도 "여전히 별로"였다. 수치(히트스톱·흔들림)는 이미 초창기보다 세다. 그래서 이번에는 **맞은 쪽이 맞았다는 게 보이게** 하는 데 집중했다.

`PlaytestProbe`로 실제 평타 연타를 돌려 측정한 값:

| 항목 | 전 | 후 (측정) |
|---|---|---|
| 맞은 적 흰 번쩍임 | 그림 위에 85% 섞기 | 완전한 흰 실루엣 약 0.06초 → 0.05초에 복귀 |
| 히트스톱 중 적 떨림 | 없음 | ±0.08칸 |
| 피격 자세 | AI 상태에 따라 늦게 | 맞는 즉시 피격 그림 + 8° 젖힘 |
| 밀림 | 넉백이 금방 사라짐 | 히트스톱 직후 약 0.8칸 밀려남 |
| 평타 화면 당김 | 없음 | 약 5%, 겹치지 않게 |
| 명중 이펙트 | 큰 애니메이션이 적을 덮음 | 작은 핵 + 링, 베기는 적 뒤로, 금속 불꽃 |
| 타격음 | "퍽" 한 겹 | "퍽" + 짧은 금속음, 매번 피치 ±6% |
| 칼 드는 예비 동작 | 0.04초 (거의 안 보임) | 0.06초 (전체 길이는 그대로) |

- 보스는 슈퍼아머라 젖히지 않고 번쩍임·떨림만 준다.
- 측정 도구가 적 AI를 켜자 적이 리아를 지나쳐 달려가 한 번도 맞지 않았다. 감지·순찰만 끄도록 도구를 고쳤다.

## 그림 화풍 통일

원인을 재 봤다. 리아·적·바닥은 약 50색의 깔끔한 도트였다. 배경 3겹과 은신처 배경은 **15만~29만 색** 그라데이션이었다. "도트 캐릭터 + AI 일러스트 배경"이 한 화면에 겹친 것이 가장 큰 티였다.

`Tools/art/style_pass.py`로 원본을 다시 처리한다. 원본 GPT 그림은 보존한다.
- 공용 팔레트 48색(골목·은신처 각각)
- 배경은 2px 도트 격자, 디더링 없음
- 외곽선은 1px 남색으로 통일
- 먼 겹일수록 채도·대비를 낮춘다

| | 1차 (Codex) | 2차 (Claude) |
|---|---|---|
| 도트 통일·캐릭터 가독성 | 좋음 | 유지 |
| 네온 | 회색으로 죽음 | **발광 마스크**로 간판·창문·탑 조명은 감쇠에서 제외, 1칸 도트 글로 |
| 밤하늘 | 갈색·회색으로 틀어짐 | 남색 유지 (채도 0.28 → 0.62) |
| 은신처 | 어둡고 칙칙함 | 전구·모니터만 발광 처리, 방 자체의 따뜻한 색 24단계 추가 |

1차 작업 중 Codex 사용 한도에 걸려서, 2차 조정은 정해 둔 규칙대로 Claude가 마무리했다.

## 저녁: 움직임 연출 (그림 대신 몸과 이펙트로)

사람 피드백: "모션이 부드럽지 않고, 돌진할 때 그냥 옆으로 미끄러지는 것처럼 보인다. 플레이어 포함."
Codex가 사용 한도에 걸려 있어서, 그림이 아닌 이 작업은 Claude가 직접 했다. 같은 이유로 대사보다 게임플레이를 먼저 다듬기로 했다.

### 리아

| 동작 | 전 | 후 |
|---|---|---|
| 대시 | 그림 한 장 평행 이동 + 불투명 잔상 | 1프레임 웅크림(0.85×1.1) → 늘어남(1.25×0.85), 12° 숙임, 정지 시 찌그러짐 0.08초. 출발 먼지·속도선 4개·카메라 밀기. 잔상 간격 0.025 → 0.016초, 끝으로 갈수록 옅게 |
| 달리기 | 5° 기울기 | 출발 0.1초 13° 숙임, 방향 전환 시 뒤로 젖힘 + 미끄럼 먼지, 발 닿는 프레임(0·4번)에 먼지 + 발소리 이벤트 |
| 점프·낙하 | 고정 0.14초 늘어남, 공중 그림 한 장 | 상승 속도에 비례해 늘었다 정점에서 원형, 낙하 속도 비례로 늘어남. 상승은 무릎 당긴 프레임(2), 낙하는 다리 벌린 프레임(4) |
| 착지 | 늘 같은 찌그러짐 | 낙하 속도 비례: 가벼우면 1.08×0.93, 높은 곳이면 1.26×0.76 + 큰 먼지 |
| 피격 | 깜빡임 | 밀려나는 쪽으로 12° 젖힘 + 빨간 덮개 1번 |

전용 그림(대시·상승·낙하·피격)을 넣을 자리를 `PlayerAnimationDriver`에 만들어 두었다. 그림이 없으면 위 대체 방식을 쓴다.

### 적 (`EnemyMotionFeel` 공용 컴포넌트, 상태 이름으로 동작)

- 공통: 이동 속도에 따라 약한 기울기·늘어남
- 깡패: 예고 때 뒤로 낮추며 뒷발 먼지, 돌진 중 앞 기울기·발밑 먼지·주황 잔상, 멈출 때 앞으로 쏠렸다 복귀
- 추적대장: 위와 같은 구조 + 바닥 긁는 금속 불꽃(중력), 벽 충돌 시 충격파 링
- 탐지 드론: 위아래 흔들림을 두 주파수(2.5·6.3)로 섞음, 이동 방향 기울기, 발사 반동

### 찾은 버그: 잔상이 불투명한 복제 인형으로 보였다

공용 스프라이트 셰이더(`SpriteFlash`)가 Unity 6에서 `SpriteRenderer.color`를 무시하고 있었다.
Unity 6부터 그림 색은 정점 색이 아니라 `unity_SpriteColor`로 들어오는데, 셰이더가 이걸 곱하지 않았다.
그래서 대시 잔상의 청록 색과 투명도가 빠져 원본 그대로 여러 장 찍혔다. 셰이더를 고친 뒤 캡처로 반투명 청록 잔상을 확인했다.

### 부드러움 점검

- 플레이어·적 모두 `Rigidbody2D` 보간이 켜져 있다.
- 카메라는 LateUpdate에서 실시간 기준으로 따라간다.
- 감속 중에는 물리 스텝도 함께 줄어든다.
- 픽셀 스냅은 없다.
- 끊김의 주 원인은 코드보다 그림 프레임 수였다(깡패 달리기 2장, 추적대장 동작마다 1~2장). 이건 다음 그림 작업에서 늘린다.

## 밤 · 효과음 다듬기

> 전체적으로 너무 ai작업의 느낌이나서 그런느낌을 최대한뺴줘

"AI 티" 세 가지(그림·대사·효과음) 중 마지막인 효과음이다. 21:10 예약 작업으로 Codex가 만들고 Claude가 검토·빌드·테스트했다.
외부 음원 없이 `Tools/audio/make_sfx.py`(표준 라이브러리 + numpy)로 전부 직접 합성했다.

### 바꾼 것

- **변주**: 휘두르기·타격·금속 타격·착지는 4개, 대시는 3개. `SfxPlayer`가 직전 클립을 피해 무작위로 고르고, 피치도 직전과 1% 이상 다르게 한다. 기존 이름(`hit`, `swing` 등)으로 그대로 부른다.
- **데이터로 추가**: `Assets/_Game/Audio/Sfx/sfx_manifest.json`에 소리 이름·클립·음량을 적으면 `SfxLibraryBuilder`(메뉴 `Roglike/Audio/Rebuild SFX Library`, 씬 빌드 때 자동)가 라이브러리를 채운다. 사람이 인스펙터에서 바꾼 음량은 다음 빌드에서도 유지된다.
- **세 층 구조**: 1.5~4ms 크랙 → 재질별 몸통 → 13~67ms 약한 반사·잔진동.
  - 타격: 살·천 "퍽" + 기계 적의 금속 공명을 한 파일로 합쳤다(따로 나던 `hit_metal` 재생은 뺐다).
  - 치명타: 더 밝은 시작 + 78Hz 부근 붐. 처치: 불규칙 간격 금속 파편 7개.
  - 몸통 대역을 소리마다 나눴다: 치명타 78Hz, 타격 165Hz, 처치 260Hz, 착지 340Hz.
- **휘두르기**: 대역 통과 노이즈 중심을 700 → 6300Hz로 쓸어 올리는 "휙". 0.115초, 타격보다 작게.
- **움직임**: 점프·착지·대시를 신발·천·금속 바닥 느낌으로 작고 건조하게. 착지에 아주 약한 물 튀김(비 오는 골목).
- **리아 피격**: 115Hz 둔탁한 몸통 + 3450Hz 회로 "찡". 적을 때리는 소리와 구분된다.
- **브레인 악셀**: 발동 `accel_on`(낮은 이중 박동 + 늘어지며 빨려 드는 고음), 자연 종료 `accel_off`(빨라지며 튀어나옴)를 `OverdriveController`에 연결했다. 발동 중 타격은 미리 합성한 `*_accel` 클립을 쓴다. 몸통·꼬리만 0.85배로 낮추고 시작 크랙은 그대로 둬서 무디지 않다.
- **믹스**: 기본 음량 타격 0.78 · 치명타 0.86 · 피격 0.72 · 처치 0.65 · 휘두르기 0.38 · 대시·착지 0.25 · 점프 0.22, 마스터 0.65.

### 전/후 수치 (첫 변주 기준)

각 칸: 길이 / 피크 dBFS / RMS dBFS / 스펙트럼 중심 Hz. "첫 5ms"는 소리 전체 에너지 중 처음 5ms가 차지하는 비율(클수록 시작이 날카롭다)로 Claude가 따로 쟀다.

| 소리 | 전 | 후 | 첫 5ms 전 → 후 | 변주 |
|---|---|---|---|---:|
