## 방 레이아웃 (Codex)

사람 피드백은 방이 계속 같고 짧아 지루하다는 것이었다. 상용 로그라이트의 레이아웃 풀·긴 방 안의 여러 조우·높낮이 지형 관례를 참고하되 새 배치로 만들고 기존 그림만 재사용했다.

- 에디터에서 굽던 폭 40칸 전투 방을 런 시작 Awake에서 생성하는 76~100칸 방으로 바꿨다. 방 종류 순서와 기존 웨이브·방별 체력 성장 ×1.18은 유지한다.
- 1지역 레이아웃 12개: 입구 2, 전투 6, 엘리트 2, 휴식 1, 보스 1. 같은 종류의 미사용 후보를 우선 뽑고 고정 시드로 재현할 수 있다.
- 단단한 블록 높이는 최대 2.4칸, 문 앞 양 끝 2칸은 평지다. 전투 방에 조우 2~3개를 두고, 구간마다 플레이어만 막는 청록 막과 카메라 경계를 설정한다.
- 강화는 웨이브 단위에서 조우 정리 단위로 바꿨다. 마지막 구간의 남은 웨이브는 연속 처리하고, 최종 강화 뒤 출구를 연다.
- 시드·중복·지형·조우·벽의 물리 충돌·남은 웨이브 처리를 검사하는 테스트를 추가하고 기존 런 진행·캡처 테스트를 조정했다.

12개 데이터의 정적 검사는 통과했다. 사용자 지정에 따라 Unity 실행은 Claude에게 맡긴다. 컴파일·실행 테스트는 아직 확인하지 않았다. 씬 YAML을 손으로 바꾸지 않았으므로 다음 작업은 Run 씬 빌더 실행, PlayMode 회귀, 한 번 점프 경로와 보스 패턴의 실제 플레이 확인이다.

파일 목록·12개 레이아웃·검증 순서는 [맵 1단계 결과](../map-stage1-result.md)에 정리했다. 커밋하지 않았다.

## 발판 걸침 버그 (사람 제보)

> 발판 살짝 낮게 점프하면 걸쳐지는 느낌 들고 바로 떨어지더라고

- **원인**: 점프가 모자라 발이 한쪽 통과 발판 속에 들어가면, 땅 판정이 그걸 "서 있음"으로 착각했다. 그 결과 착지 소리가 나고, 2단 점프가 다시 채워지고, 낙하 속도가 -1로 눌렸다. 하지만 발판이 실제로 받쳐 주지 않아 천천히 뚫고 떨어졌다.
- **고침 1**: 한쪽 통과 발판은 발이 윗면에서 0.08 안쪽에 있을 때만 땅으로 본다.
- **고침 2**: 발판 끝 보정을 넣었다(할로우 나이트·셀레스트식). 정점 근처에서 발이 윗면보다 0.4 안쪽으로 낮으면 위로 올려 세운다. 단, 몸 가운데가 발판 위에 있고 머리 위가 비어 있어야 한다. 막힌 벽 모서리는 그쪽으로 움직일 때만 올린다.
- **측정**: 실제 점프 정점은 발 기준 2.84다(이론값 3.0). 0.26 모자란 발판에는 올라서고, 0.9 모자라면 걸치지 않고 바닥까지 떨어진다(`LedgeAssistTests`).

## 보스 권능 (검은 마법사 3페이즈 권능 구조 참고)

> 하늘에서 떨어지는거 발판으로 막자는게 검은마법사 3페 윗권능 패턴같이 만들어달라한거라

참고한 구조:
- 윗권능: 늘 있는 긴 발판 아래로 숨는다.
- 아랫권능: 발판 위로 올라간다.
- 둘 다 일반 패턴과 따로 주기로 온다.

예전 공습은 엄폐판이 즉석으로 생기고 작은 탄이 흩뿌려져서, 자리를 미리 생각하는 맛이 없었다. Codex가 구현하던 중 사용 한도에 걸려(02:10 재개), 남은 부분은 Claude가 마무리했다.

| 항목 | 전 | 후 |
|---|---|---|
| 보스 방 발판 | 폭 6 두 개 | **폭 9 긴 발판 두 개**(윗면 3.0). 아래에 서고, 한 번 점프로 오른다 |
| 하늘 권능 | 공습탄 11발 + 즉석 엄폐판 | 예고 2.2초(붉은 띠가 내려옴, 발판 아래 청록 안전 표시) → 0.45초 빛기둥이 방 전체를 덮는다. 발판 아래가 아니면 최대 체력 30% |
| 바닥 권능 | 없음 | 예고 1.8초(바닥 붉은 선, 발판 위 청록) → 바닥 전류. 맞는 건 **터지는 순간 0.15초**라 점프 타이밍으로도 피한다. 최대 체력 25% |
| 주기 | 일반 패턴 무작위 3종 | 일반은 돌진·휘두르기(같은 것 3연속 금지). 권능은 18초 뒤 첫 발동, 이후 32초(분노 24초)마다 하늘→바닥 교대. 분노 진입 시 다음 권능을 6초 안으로 당긴다 |
| 가독성 | 바닥 표시 | 권능 예고 시작에 화면 흔들림 + 붉은 비네트 |

Claude가 고친 것:
- 바닥 권능은 0.5초 내내 판정이 있어서 점프해도 착지 순간 맞았다. 터지는 순간 0.15초만 판정하도록 바꿨다(연출은 0.5초 유지).
- 패턴 이름(`CurrentPattern`)이 직접 시작한 패턴에서 빈 값이 되던 문제.
