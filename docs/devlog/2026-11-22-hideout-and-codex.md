# 2026-11-22 · 지하 은신처에서 깨어나고, 도감과 보스 공격 예고를 달다

작성: Claude

## 한 일 요약

어제 받아 둔 은신처 그림으로 **지하 은신처 거점, 대사 상자, 닥, 기억 조각 1**을 만들었다. 이어서 **도감(티코의 추적 단말)**과 **추적대장 공격 위치 예고**를 붙였다. 코드는 Codex가 쓰고, Claude가 검토·빌드·테스트·화면 캡처를 맡았다. 도감 작업 끝부분에서 Codex 사용 한도가 끝나서, 이미 만들어진 코드의 마무리(깨진 한글, 캡처 테스트, 문서)는 Claude가 이어서 했다.

## 만든 것

### 1. 지하 은신처 (새 씬 `Hideout`)

- 게임 시작과 런이 끝난 뒤(승리·사망 모두) 은신처로 온다. 결과 화면 → 강화소로 바로 가던 흐름을 **결과 → 은신처 → 닥과 대화 → 강화소 → 지상 계단으로 출발**로 바꿨다.
- 배치: 은신처 배경(따뜻한 전구, 오른쪽 계단의 청록 빛) + 소품 5개(닥의 진료 침대, 공구 작업대, CRT 모니터, 커피 코너, 지상 계단 문) + 닥(4프레임 대기).
- 상호작용: 가까이 가면 "↑ / Y 대화 · 닥", "↑ / Y 살펴보기"(빈 침상), "↑ / Y 출발 · 지상 계단 → 하층 네온 골목". 오른쪽 끝으로 걸어가도 출발. 장면 전환은 짧은 페이드(편도 0.3초).
- 닥 외 생존자는 아직 없다 → 빈 침상을 살펴보면 리아가 한마디 한다.

### 2. 대사 상자 (데이터로 늘리는 구조)

- `DialogueData`(한 장면) · `SpeakerData`(이름·초상·이름 색) · `StoryData`(장면 묶음) 에셋. **장면 추가 = 에셋 추가.**
- 아래쪽 패널, 리아는 왼쪽·상대는 오른쪽 초상, 초당 40자 타자 효과(감속 영향 없는 시간), 깜빡이는 ▼.
- X / Z / Enter / 패드 A = 줄 완성·다음, **Esc / Tab / Select = 대화 전체 건너뛰기.**
- 대화 중에는 게임 시간과 입력이 멈추고 끝나면 브레인 악셀·히트스톱 상태가 그대로 돌아온다. 이를 위해 `TimeController`에 "누가 멈췄는지" 따로 세는 정지(소유자별)를 추가해서 메뉴 정지와 서로 풀어 버리지 않게 했다.
- 한 번만 나오는 대화(첫 기상, 기억 조각)는 `meta.json`에 기록한다.

### 3. 대사 (Codex 작성, 일부)

| 장면 | 대사 |
|---|---|
| 첫 기상 | 리아 "여기… 은신처? 닥, 그 붕대는 또 뭐예요?" / 닥 "네 상처 좀 나눠 가졌지. 눈 떴으면 됐다. 외상은 천천히 갚아." |
| 첫 출발 (벨모어, 비밀 통신) | "들리느냐, 리아. 비밀 채널이다. 목의 가짜 포트는 잘 가렸겠지?" |
| 재출발 | 벨모어 "또 지상인가, 리아. 검보다 고집이 먼저 닳겠구나." |
| 추적대장 입장 | 벨모어 "추적대장이다. 저 갑옷 안의 인간도 우리를 괴물이라 부르지." / 리아 "누가 괴물인지는 몰라도, 길 막는 솜씨는 확실하네요." |
| 사망 (셋 중 하나) | "아, 이건 아프네… 닥 붕대값 또 늘겠다." |
| 닥 (돌아가며) | "힘은 무턱대고 끌어오는 게 아냐. 남길 줄도 알아야지." / 리아 "알았어요. 귀환할 몫은 꼭 남겨 둘게요." |

### 4. 기억 조각 1 — 정화의 밤

추적대장을 처음 쓰러뜨리면 그림(식탁 밑에 숨은 어린 리아와 동생, 문가의 사냥꾼 군화)이 떠오르고 세 줄이 나온다.

> 정화의 밤. 식탁 밑에서 나는 동생의 손을 꼭 잡았다.
> 문가에 멈춘 사냥꾼의 군화. 숨소리마저 삼켰다.
> 놓지 않으려 했는데… 작은 손이 내 손에서 미끄러졌다.

### 5. 도감 — 티코의 추적 단말

- 티코는 아직 합류 전이라, 은신처의 CRT 모니터를 "티코의 추적 단말"로 써서 먼저 열었다. "↑ / Y 보기 · 도감".
- 분류 탭 **적 / 보스 / 기억 조각**, 위에 "도감 1 / 4" 같은 개수. 안 만난 항목은 **검은 실루엣 + ???**, 고르면 큰 그림·이름·설명·"처치 n · 처음 만난 런 n".
- 런 중 처음 만나면 오른쪽 위에 "도감에 새로 등록: 마도기 깡패" 알림(3초).
- 항목 = `CodexEntryData` 에셋 4개(`Data/Codex/`). 새 적 = 새 에셋.
- 도감 문구 (Codex 작성):
  - 마도기 깡패 — "빌린 마도기로 골목을 제 땅처럼 누빈다. 전지가 깨지면 큰소리도 멎는다." / 과부하: "한계를 넘긴 전지. 더 빠르고, 더 질기다."
  - 탐지 드론 — "네온 사이를 떠돌며 마력이 빈 자리를 찾는다. 숨을 참아도 흔적은 남는다."
  - 추적대장 — "진압봉과 공습 신호로 골목을 봉쇄하는 사냥 부대장. 갑옷 안의 인간은 누가 괴물인지 묻지 않는다."
  - 기억 조각 1 · 정화의 밤 — "잊었다고 믿었던 밤. 손바닥에는 아직 작은 손의 온기가 남아 있다."

### 6. 추적대장 공격 위치 예고

"빨간 표시가 정확히 맞을 자리에" — 졸업 전시 리뷰에서 고른 아이디어.

| 공격 | 예고 | 시간 (바꾸지 않음) |
|---|---|---|
| 돌진 | 보스부터 벽·낭떠러지까지 바닥에 붉은 길 | 0.7초 |
| 휘두르기 | 진압봉 판정 상자 크기의 붉은 영역 | 0.45초 |
| 공습 | 공습탄마다 착탄 지점에 붉은 원 (생성할 때 착탄 x를 정함) | 0.6초 |

- 재사용 가능한 `GroundWarning`(미리 만들어 두고 돌려 씀, 프레임마다 할당 없음). 게임 시간 기준이라 브레인 악셀 중에는 예고도 같이 느려진다. 보스 피해·체력·패턴 시간은 그대로.

## 남은 문제

- **공습 착탄 원이 위쪽 난간 발판에 찍힌다**: 공습탄은 원래부터 아래로 처음 닿는 바닥(한쪽 통과 발판 포함)에 떨어진다. 바닥에 선 리아에게는 위협이 안 되는 탄이 생긴다 → 발판을 무시하고 땅까지 떨어뜨릴지 정해야 한다.
- 도감 패널이 반투명이라 뒤의 은신처 그림이 많이 비친다. 글자는 읽히지만 더 어둡게 하는 편이 낫겠다. 도감 등록 알림이 도감 패널 위에도 겹쳐 보인다.
- 기억 조각 그림 뒤 배경을 어둡게 깔면 더 몰입될 것 같다.
- 은신처 소품(침대·작업대·모니터)이 배경 그림에 이미 있는 가구와 겹쳐 조금 복잡하다.
- 은신처 왼쪽 끝 캡처에 하늘색 띠가 보였다 — 배치 모드 캡처의 화면 비율 탓으로 보이며 실제 16:9 화면에서는 확인 못 했다.
