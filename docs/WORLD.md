# 세계관·스토리·맵 설계 (초안 v0.1)

> 상태: **초안 — 사람 확인 전.** 확정되면 [GDD](./GDD.md)에 요약을 옮기고, 지역·적·보스는 이 문서를 기준으로 만든다.
> 원칙: 이름·설정·캐릭터는 모두 오리지널. 밝은 판타지 톤 유지, 지금 그림(주인공·숲·바닥)을 그대로 쓴다.

## 1. 한 줄 요약

**멈춰 버린 세상에서, 시간을 늦추는 검사 리아가 세상의 시간을 훔친 시계공 벨모어를 쫓아 시계탑을 오른다. 쓰러질 때마다 그녀의 스카프가 시간을 되감아 새벽의 마을로 돌려보낸다.**

## 2. 세계

- 세상의 시간은 산꼭대기 **아이온 대시계탑**이 흐르게 한다. 시계탑을 지키는 이들이 **시계지기단**.
- 어느 밤 시계탑이 멈췄다. 그 순간 세상은 **멈춘 시간**(공중에 멈춘 낙엽, 떨어지다 만 빗방울)과 **흘러넘친 시간**(태엽처럼 뒤틀린 짐승들)으로 찢겼다.
- 시계탑의 심장인 **네 개의 톱니**가 빠져나가 네 지역의 수호자에게 흩어졌다. 톱니를 되찾아야 시계탑을 다시 돌릴 수 있다.

## 3. 주인공 — 리아

- 시계지기단의 막내 견습생. 은발에 청록 줄무늬, **청록 스카프**, 푸르게 빛나는 검 **초침**.
- 스카프는 스승이 남긴 **시간의 실**로 짠 것. 리아가 쓰러지면 실이 풀리며 시간을 **그날 새벽**으로 되감는다. → 죽으면 마을에서 다시 시작하는 이유(로그라이트 반복).
- 능력: 시간을 늦춘다. 게임의 **오버드라이브** = 스카프의 실을 끝까지 당겨 주변 시간을 늦추는 것.
- 성격: 밝고 고집 셈. 실패해도 "한 번 더"를 외치는 타입이라 반복하는 게임 구조와 잘 맞는다.

## 4. 주적 — 정지의 시계공 벨모어

- 시계지기단의 전 단장이자 **리아의 스승**. 시계탑을 멈춘 장본인.
- 동기: 오래전 잃어버린 가족과의 **행복했던 한순간**을 영원히 붙잡으려고 세상의 시간을 멈췄다. "변하지 않으면 아무것도 잃지 않는다."
- 악역이지만 이해할 수 있는 인물. 리아에게 시간의 실을 짜 준 것도 그다 (리아가 되감길 때마다 그도 그것을 안다).
- 등장 방식
  - 런 시작·지역 입구에서 짧은 독백·조롱 ("또 왔구나, 리아. 몇 번째 새벽이지?")
  - 각 지역 보스는 그가 톱니를 맡긴 **수호자**. 보스를 쓰러뜨릴 때마다 그의 과거 기억 조각이 풀린다.
  - 최종 보스: 시계탑 꼭대기의 벨모어 (2페이즈 — 두 번째는 시간을 **빠르게 감는** 능력으로 오버드라이브와 정반대).
- 엔딩 후보: 시계탑을 다시 돌리면 벨모어가 지키려던 순간도 흘러간다. 그를 쓰러뜨리는 엔딩 / 함께 그 순간을 보내 주는 엔딩.

## 5. 지역 4곳 (한 판 = 1 → 4 순서)

| # | 지역 | 분위기 | 지형 특징 | 수호자 (보스) |
|---|---|---|---|---|
| 1 | **멈춘 숲** | 공중에 멈춘 낙엽·꽃잎, 밝은 초록 (지금 그림) | 기본 발판, 멈춘 통나무 발판 | **태엽 사슴왕** — 뿔이 톱니인 거대한 사슴. 돌진, 뿔 휘두르기, 낙엽 폭풍 |
| 2 | **거꾸로 흐르는 협곡** | 모래가 위로 흐르는 황금빛 협곡 | 위로 떠오르는 모래 기둥(밟으면 올라감) | **모래시계 마녀** — 원거리 마법, 모래시계를 뒤집어 패턴 반복 |
| 3 | **진자의 성채** | 거대한 진자가 흔들리는 돌 성채, 저녁 노을 | 흔들리는 진자 발판, 칼날 진자 함정 | **진자 기사** — 방패와 철퇴, 진자처럼 크게 휘두름 |
| 4 | **아이온 대시계탑** | 거대한 톱니바퀴 내부, 밤하늘 | 돌아가는 톱니 발판 | **벨모어** (최종) |

- 지역마다 **같은 맵**이 나온다 (반복 OK). 대신 적 배치·강화·이벤트가 런마다 바뀐다.
- 보스를 처음 쓰러뜨리면 다음 지역이 열리고 마을이 조금 되살아난다. M4에서는 **1지역 완성**이 먼저.

## 6. 적 — 슬라임 교체

슬라임 대신 **"흘러넘친 시간에 태엽처럼 뒤틀린 생물"**로 통일한다. 모두 몸 어딘가에 톱니·태엽·시계 부품이 박혀 있어 한눈에 이 세계의 적이다.

| 지역 | 적 | 역할 | 패턴 |
|---|---|---|---|
| 1 | **태엽 멧돼지** | 돌진형 | 앞발 긁기 예고 → 직선 돌진, 벽에 부딪히면 잠깐 기절 |
| 1 | **톱니 다람쥐** | 원거리 | 나무 위에서 작은 톱니를 던짐, 가까이 가면 도망 |
| 1 | **멈춘 꽃 정령** | 방해형 | 근처를 잠깐 느리게 만드는 꽃가루 (플레이어 감속) |
| 2 | 유리 전갈 / 모래 술사 / 시곗바늘 박쥐 | | (2지역 제작 때 상세화) |
| 3 | 태엽 병정(방패) / 진자 추 / 녹슨 갑옷 | | |
| 공통 엘리트 | 같은 적의 **"과부하"** 버전 | 강화형 | 붉은 톱니 빛, 체력·속도 증가, 처치 시 보상 추가 |

## 7. 맵 구조 (지금: 하나의 전투장 재사용 → 바꾼다)

**한 지역 = 가로로 이어지는 방 5~6개.** 방은 손으로 짠 고정 맵, 적 배치만 랜덤.

```text
[입구] → [전투 방] → [전투 방] → [휴식 or 상점] → [엘리트 방] → [보스 방]
```

- **전투 방**: 화면 2~3개 폭의 가로 맵. 문이 잠겨 있고, 적을 다 잡으면 오른쪽 문이 열린다 → 강화 3택1 → 다음 방.
- **휴식 방**: 체력 회복 또는 강화 1개 중 선택.
- **상점 방**: 런 안에서만 쓰는 재화(톱니 조각)로 강화·회복 구매.
- **엘리트 방**: 엘리트 1~2마리, 희귀 이상 강화 확정.
- **보스 방**: 넓은 평지 + 보스 전용 연출 (입장 대사, 체력바).
- 방 사이 이동은 짧은 페이드. 카메라는 방 경계 안에서만 움직인다.

## 8. 거점 — 새벽 마을

- 시간이 멈춘 작은 마을. 쓰러지면 스카프가 되감아 이 마을의 **새벽**으로 돌아온다. 걸어 다닐 수 있다 (같은 조작).
- 처음엔 사람들이 굳어 있고, **보스를 쓰러뜨릴 때마다 한 명씩 다시 움직인다.**

| NPC | 처음 | 하는 일 |
|---|---|---|
| **대장장이 도르** | 처음부터 깨어 있음 | 영구 강화 (지금의 강화소) |
| **시계공 할머니 미라** | 1지역 보스 후 | 스킬 해금·교체 |
| **여관 주인 펠** | 2지역 보스 후 | 런 시작 버프 1개 선택 |
| **꼬마 티코** | 3지역 보스 후 | 도감 (적·보스·벨모어의 기억 조각) |

- 마을 오른쪽 끝 **시계탑 길**로 나가면 런 시작.

## 9. 이야기를 보여 주는 방법 (가볍게)

- 컷신 대신 **짧은 대사 상자** (2~4줄). 스킵 가능.
- 런 시작 / 보스 입장 / 보스 처치 / 마을 NPC 대화 / 죽었을 때 리아 한마디.
- 보스 처치 시 **벨모어의 기억 조각**(한 장짜리 일러스트 + 3줄) — GPT 이미지로 만들기 좋은 형식.

## 10. 만드는 순서 제안

1. **1지역 '멈춘 숲' 세로 조각**: 방 5개 구조, 문·방 전환, 태엽 멧돼지·톱니 다람쥐, 보스 태엽 사슴왕 (그림은 GPT로 몇 장씩)
2. **새벽 마을**: 걸어 다니는 거점, 대장장이(강화소 이전), 런 시작 길
3. 대사 시스템 + 벨모어 등장 대사
4. 2~4지역은 1지역 틀을 복사해 콘텐츠만 추가

## 11. 정해야 할 것

- 이름들 (리아·벨모어·지역명) 괜찮은지
- 엔딩 방향 (쓰러뜨림 / 보내 줌 / 둘 다)
- 한 판 길이: 4지역 × 방 6개 ≈ 25~30분 (GDD 목표와 맞음)
