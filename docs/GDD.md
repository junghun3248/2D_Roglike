# 게임 기획서 (초안 v0.1)

> 가제: 미정 · 장르: 2D 횡스크롤 액션 로그라이트 · 엔진: Unity 6 · 개발: 1인 + AI(Claude, Codex)

## 1. 한 줄 소개

밝은 판타지 세계에서, 타격할 때마다 시간이 멈칫하고 화면이 꽂히는 손맛의 횡스크롤 액션 로그라이트.
런이 진행될수록 데미지 숫자가 폭발적으로 커지는 **성장 체감**이 핵심이다.

## 2. 핵심 재미 (디자인 기둥)

모든 기능은 아래 셋 중 하나 이상을 강화해야 한다. 어느 것도 강화하지 않으면 만들지 않는다.

1. **타격 쾌감** — 때리는 순간이 기분 좋아야 한다. 히트스톱, 화면 흔들림, 줌, 슬로모션.
2. **딜 성장 체감** — 초반 `12` 데미지가 후반 `1.2억`이 된다. 강해지는 게 눈과 숫자로 보인다.
3. **빌드의 재미** — 런마다 다른 스킬·아이템 조합, 조합이 맞아떨어지는 순간 숫자가 폭발한다.

## 3. 런 구조

- 한 런은 **최대 약 30분**. 초반엔 자주 죽어 짧게 끝나고, 실력·영구 성장이 쌓일수록 끝까지 간다.
- 지역 3~4개 × (일반 구역 여러 개 → 엘리트 → 지역 보스), 마지막에 최종 보스.
- 현재 1지역 **멈춘 숲**은 같은 씬에서 오른쪽으로 이어진 6개 고정 방: 입구 → 전투(2웨이브) → 전투(3웨이브) → 휴식 → 엘리트 → 태엽 사슴왕. 보스 처치로 이번 런은 승리한다.
- 1지역 전투 웨이브는 2/2, 2/3/4마리이며 방의 동시 생존 상한은 4마리다. 엘리트 방은 엘리트 1마리와 일반 1마리, Prototype은 최대 3마리다.
- 다음 방 입장 시 뒤쪽 문이 잠기며, 전투 클리어 후 회복·강화 선택을 마치고 걸어서 다음 방으로 간다. 휴식은 최대 체력 40% 회복 또는 강화 1개 선택이며, 휴식 강화와 엘리트 보상은 희귀 이상 우선(후보 부족 시 다른 희귀도로 보충)이다.

| 시간대 | 체감 목표 |
|---|---|
| 0–5분 | 기본기 익히기, 첫 스킬 획득 |
| 5–15분 | 빌드 방향이 잡힘 |
| 15–25분 | 시너지 완성, 숫자 폭발, 몹을 쓸어버림 |
| 25–30분 | 최종 보스로 성장 확인 |

## 4. 전투

### 기본 조작
- 이동 ←/→·패드 왼쪽 스틱/십자키, 점프 Z(2단), 대시 C, 오버드라이브 Space. 키보드 방향 조합은 ↑/↓만 사용한다. 패드 배치는 유지한다.
- X(마우스 왼쪽·패드 West)를 누르고 있으면 단일 베기를 반복한다. 콤보·마무리 타격 없이 준비 0.04초, 판정 0.08초, 회복 0.15초. 0.45초 이내 반복은 베기 각도만 상하 교대한다. 공중 일반 베기는 정상 중력과 좌우 조작을 유지한다. 첫 명중만 수직 속도를 최소 3으로 올리며 착지·점프·2단 점프로 초기화된다. 빗맞히면 체공 보정이 없다.
- 대시는 지상 쿨다운 없이 종료 후 0.06초 간격으로 다시 쓸 수 있다. 무적은 시작 0.1초만. 공중 대시는 1회이며 착지·2단 점프로 회복한다.
- 대시 중 또는 종료 후 0.15초 이내 X: 관성을 유지하며 전방을 관통하는 돌진 찌르기.
- 지상 ↑+X: 적을 높이 띄우고 플레이어도 작게 뛰는 올려베기.
- 공중 ↓+X: 수직 내려찍기. 착지 시 범위 공격으로 적을 튕겨 올린다. 무적은 없고 낙하 중 점프는 불가하다.
- 지상·공중 V(마우스 오른쪽·패드 North)를 짧게 눌렀다 떼면 강공격. 0.45초 이상 모았다 떼면 약 4단위 무적 돌진 후 강한 차지 일격(처치 시 줌·슬로모션).
- 차지 중 주변은 0.4배속, 플레이어 시간은 정상이며 공중에서 천천히 낙하한다. 피격·대시·스킬로 취소되고 옅은 청록 화면 효과를 표시한다. 오버드라이브 중에도 차지할 수 있으며 감속 배율은 중복하지 않는다.
- 스킬 슬롯 키보드 A/S/D/F, 패드 East/RT/LT/오른쪽 스틱 누르기. 기본 순서: 정지 구역, 회전 베기, 검기, 내려찍기.
- 정지 구역: 전방 3단위에 시계 문양을 놓고 0.15초 뒤 폭발(1.5배 피해). 반경 3.5단위 적을 1.5초 정지(보스 0.5초), 정지 중 받는 피해 +30%. 쿨다운 6초. Run 시작 스킬이다.
- 강화·휴식·강화소·결과 화면은 기존 키와 X로 확정한다. Z는 확정에 사용하지 않는다.

- 기본 카메라는 바닥 상단이 화면 아래에서 약 20~25%에 오도록 위쪽 공간을 확보한다. 방 경계·전방 보기·타격 줌은 유지한다.

### 타격감 (모든 공격 공통)
- 일반 베기: 히트스톱 지상 0.075초/공중 0.06초, 흔들림 0.22/0.18, 넉백 (6, 2), 경직 0.3초. 지상 명중은 뒤로 0.4단위/0.08초 반동. 방향성 카메라 킥·스파크·청록/흰 명중 섬광과 절차 합성 효과음을 사용한다. 치명타는 히트스톱 1.4배와 약한 줌(0.94), 명중 섬광 1.25배. 빗맞힘은 베기 VFX와 스윙 소리만 재생한다.
- 베기 VFX는 처음부터 완전한 크기의 청록 초승달 4프레임을 비감속 시간 약 0.112초로 재생한다. 상향 베기는 상하 반전, 왼쪽 공격은 좌우 반전하며 점차 얇아지고 사라진다. 내려찍기 착지는 금색 지면 충격파 4프레임을 사용한다.
- **히트스톱**: 명중 시 수 프레임 정지 (강공격일수록 길게).
- **카메라 흔들림**, **히트 플래시**(적이 하얗게 번쩍), **넉백·경직**, 타격 파티클·효과음.
- **처치 연출**: 강한 마무리 일격·엘리트 처치 시 짧은 줌인 + 슬로모션.

### 특수기: 오버드라이브 (가칭)
- 타격·회피로 게이지 충전 → 발동 시 **세상은 느려지고 플레이어만 정상 속도**로 움직인다.
- 발동 중: 잔상 효과, 화면 색감 변화, 효과음 저음화.
- 발동 중 명중 시 **카메라가 타격 지점으로 줌인**하며 짧게 멈칫.
- 지속 시간·감속 비율·충전량은 업그레이드 대상 (빌드 축이 될 수 있음).
- 참고 감성: 시간 감속 연출 계열 액션. 이름·연출은 오리지널로 만든다.

## 5. 성장

### 런 안 (빌드)
- 레벨업·보상 시 **3개 중 1개 선택** (스킬 / 스킬 강화 / 패시브).
- 아이템: 런 동안 유지되는 효과.
- **곱연산 계층**: `기본 공격력 × 스킬 배율 × 피해 증가 × 치명타 × 시너지`. 계층이 곱해지기 때문에 후반 숫자가 폭발한다.

- 웨이브를 정리할 때마다, 그리고 구역 클리어 때 강화를 고른다. 선택지가 마음에 안 들면 **다시 뽑기(R)**, 기본 1회.

### 시너지 (롤체식 계열)
- 강화마다 계열 태그가 붙는다: 검술(공격력), 치명, 질풍(속도), 파괴(피해 증가·최종 피해), 과부하(오버드라이브), 생존(체력).
- 같은 계열을 **2 / 4 / 6개** 모으면 단계 보너스가 켜진다. 최고 단계만 적용되고, 높은 단계일수록 크게 뛴다.
- 좌측 시너지 패널에 진행도가 보이고, 단계가 오르면 알림이 뜬다.

### 런 밖 (영구 성장)
- 런이 끝나면 **결정**을 얻는다: 클리어한 구역 수 × 5, 처치 수 ÷ 2, 승리 시 +40.
- 결과 화면 다음 **강화소**에서 결정으로 영구 능력치를 산다: 공격력, 체력, 치명타 확률, 피해 증가, 이동 속도, 오버드라이브 충전, 다시 뽑기 횟수.
- 저장 위치: `Application.persistentDataPath/meta.json`.
- 후일: 새 스킬·아이템 해금, 새 캐릭터.

### 데미지 숫자
- 크고 굵은 폰트, 연타 시 겹쳐 쌓임, 치명타는 다른 색·크기.
- 큰 수는 한국식 단위 표기: `12,345` → `1.2만`, `123,456,789` → `1.2억`.

## 6. 분위기·아트

- **밝고 경쾌한 판타지.** 채도 높은 배경, 귀여운 몬스터, 화려한 스킬 이펙트.
- 초기 프로토타입은 단순 도형·무료 에셋으로 재미를 먼저 검증하고, 이후 아트 확정.
- 미정: 도트 vs 일러스트 스타일, 주인공 설정.

## 8. 개발 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| M0 셋업 ✅ | 저장소, Unity 프로젝트, AGENTS.md | 빈 씬 빌드됨 |
| M1 손맛 프로토타입 ✅ | 이동·공격·대시, 적 1종, 타격감, 오버드라이브 | **때리는 게 재밌다** |
| M2 런 루프 ✅ | 구역 진행, 3택1 성장, 보스 1, 사망·재시작 | 한 런이 처음부터 끝까지 돌아감 |
| M3 성장 ✅ | 곱연산 빌드, 시너지, 리롤, 데미지 숫자, 영구 성장 | 숫자 폭발이 체감됨 |
| M4 콘텐츠 | 지역·적·스킬·아이템 확장, 아트 교체 | 30분 런 완성 |
| M5 출시 준비 | Steam 페이지, 트레일러, 데모 | 위시리스트 모집 시작 |

M1에서 재미가 없으면 그 다음으로 넘어가지 않고 손맛부터 고친다.

## 9. AI 협업 규칙

- 저장소 루트 `AGENTS.md`에 구조·코드 규칙을 적고, Claude와 Codex 모두 이를 따른다.
- 커밋 메시지: `type(scope): 한국어 설명` 형식 (예: `feat(combat): 히트스톱 추가`).
- 한 작업 = 한 기능 단위 (예: "적 1종 추가", "대시 무적 프레임"). 큰 작업은 쪼갠다.
- 에디터 작업(씬 배치, 프리팹 조립, 수치 손맛 조정)은 사람이, 코드·데이터 구조는 AI가 주로 맡는다.
