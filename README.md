# 2D_Roglike (가제)

밝은 판타지 세계의 2D 횡스크롤 액션 로그라이트.
타격할 때마다 시간이 멈칫하고 화면이 꽂히는 손맛, 런이 진행될수록 폭발하는 데미지 숫자가 핵심이다.

- 기획서: [docs/GDD.md](./docs/GDD.md)
- 개발 규칙 (사람·AI 공통): [AGENTS.md](./AGENTS.md)

## 개발 환경

- Unity `6000.3.10f1` (Unity Hub에서 이 버전으로 열기)
- 2D URP · Input System · Cinemachine 3
- Git LFS 필요: 클론 후 `git lfs install`
